# ⚡ KeyFlow — визуальная автоматизация Windows

Блочный редактор автоматизаций в духе **ComfyUI**: ноды, соединённые линиями,
реагируют на **глобальные горячие клавиши** и выполняют действия в Windows —
клики мышью, нажатия клавиш, скриншоты, переменные, запуск программ, сайты.

GUI работает **в браузере**, процесс живёт **в консоли** (пока консоль открыта —
программа работает). Редактор построен на движке **litegraph** — том же, что и
ComfyUI, а «красивые линии по сетке» — адаптация алгоритма
**CircuitBoard** из плагина ComfyUI `quick-connections`.

---

## Запуск

```bat
run.bat
```

или вручную: `python server.py`

* Консоль держите открытой — это процесс программы.
* Браузер откроется сам на `http://127.0.0.1:8760` (порт — в `settings.json`).
* Кнопка **▶ Запустить** включает отлов клавиш, **■ Остановить** — выключает.

Зависимости уже лежат в папке `vendor/`. Если удалили — восстановите:
`pip install --target vendor -r requirements.txt` (pynput, mss, requests).

## Возможности

### Редактор (как в ComfyUI)
* **Двойной клик по пустому месту** (или ПКМ → Add Node) — поиск по всем нодам:
  большое окно, **название + описание под ним**; при наведении — превью ноды
  с полем названия, точно по её размеру. Пустой запрос показывает **частые ноды
  сверху** («При запуске», Горячая клавиша, Клик мышью, Число, Текст и др.).
  Кнопка **⚡ Первое включение** рядом с поиском оставляет только ноды-триггеры
  (такие ноды помечены тегом в списке). Ищет и по русским названиям
  («скрин», «горячая»). Одиночный клик мимо — закрыть.
* **Своя система соединений**: зажали пин — линия «прилипла» к курсору (цвет = тип).
  Отпустили **на ноде** — подключится к первому совместимому входу (занятый вход
  перехватит провод). Отпустили **на пустом месте** — поиск подходящих нод,
  выбранная подключается сама. От входа тянется так же, в обратную сторону.
* **Несколько линий во вход «in»** — события от разных нод запускают одну
  цепочку с любого из них.
* **ПКМ по пину** — своё меню: каждая связь отдельной строкой с именем ноды
  («→ Скриншот : in»), «отсоединить все», а у выхода — **переименовать**.
* Тип `any` универсален; `number ↔ bool` совместимы; **текст и число не совместимы**
  (координаты x/y принимают только числа, `path`/текстовые входы — только текст;
  текст `123,45` к координатам подключите через «Разбор позиции»), `string ↔ pos`
  тоже ("x,y"). События к данным не подключаются.
* Правый клик на ноде — меню; на пустом — меню холста.
* **Выделение рамкой** — простое перетаскивание по пустому месту (как в ComfyUI);
  перетаскивание одной выделенной ноды двигает **всё выделение**, при сбросе
  **все** выделенные выравниваются по сетке (если включена).
  Новые ноды тоже встают на сетку. **Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y)** — отмена/возврат.
* **Линии**: по умолчанию плавные кривые, точно идущие от пина к пину; опционально
  стиль «плата» (по сетке, обходят ноды) — в настройках. Кнопкой 🔗 (правый
  нижний угол, под миникартой) линии можно **скрыть/показать**.
* **Миникарта** (🗺 в правом нижнем углу): ноды цветами категорий, рамка
  видимой области, клик/перетаскивание — переход.
* Из одного выхода можно вести **несколько линий** — они выстреливают вместе,
  но ноды исполняются **строго по одной** (глобальная очередь): следующая
  стартует только после завершения предыдущей. Эмуляции клавиш/мыши в разных
  ветвях не мешают друг другу.
* Ползунки-числа: **зажмите и ведите мышью** — значение меняется; короткий
  клик — ввод с клавиатуры. Размер ноды при растяжении тоже выравнивается по сетке.
* Слева — **панель workflow**: список, создание, удаление (☰ — свернуть),
  **экспорт/импорт .json** (кнопки внизу панели).

### Группы
**Группа (Ctrl+G):** выделили ноды → Ctrl+G → вокруг них рамка-группа (как в ComfyUI).
Заголовок рамки рисуется **внутри** неё над нодами (при создании рамка сразу
создаётся с верхним отступом — ноды не «заходят» на надпись). Группа двигается
**только за шапку**, угол растягивает, ПКМ по рамке → Edit Group (Title —
переименовать, Remove — удалить). **Клик по шапке выделяет группу** (подсветка
рамки, ноды внутри НЕ выделяются), Delete при выделенной группе — удалить её
рамку (ноды остаются). Ноды внутри остаются обычными нодами.

**Сабграф (Ctrl+Shift+G):** полноценная группа-нода (как «Convert to Subgraph» в
ComfyUI): внешние провода автоматически станут входами/выходами на корпусе,
**двойной клик** — редактирование внутри (хлебные крошки, Esc — выход). Внутри
сабграфа стоят две **ноды-маркера «Входы» и «Выходы»** (как Input/Output в
ComfyUI) — их можно перетаскивать, позиции сохраняются: перетащите провод от
входа ноды на маркер «Входы» — появится вход группы, от выхода — на «Выходы» —
выход группы. К каждой промоутед ноде от маркера идёт **настоящая линия** внутри
сабграфа. **Маркеры полупрозрачные** (пины на них — плотные). **ПКМ по пину
маркера → «🗑 Удалить точку»** — точка входа/выхода снимается с корпуса
(у наружных проводов слоты пересчитываются автоматически). ПКМ на ноде внутри —
«Вход на группу» / «Выход на группу» / **вынести параметр на группу**; можно и
**потянув от поля виджета** к маркеру «Входы» (пунктирная линия): у ноды появится
пин параметра, на корпусе — поле редактирования + точка входа, значение с провода
заменяет значение поля (и внутри, и снаружи), поле можно оставить как значение
по умолчанию. ПКМ на группе — «Переименовать» / «Распаковать группу»
(маркеры при распаковке не выходят на холст). Движок исполняет сабграф целиком
(маркеры пропускает).

### Триггеры
| Нода | Что делает |
|---|---|
| **Горячая клавиша** | срабатывает по сочетанию: `ctrl+alt+s`, `f5`, и **несколько зажатых букв**: `a+s+d` (зажать все три) |
| **Кнопка мыши** | срабатывает по кнопке мыши (в т.ч. боковым x1/x2), клик или двойной |
| **Первое включение** (бывш. «При запуске») | срабатывает при нажатии ▶ |
| **Интервал** | источник: каждые N секунд, пока процесс запущен (вход не нужен) |
| **Интервал-переключатель** | 1-е нажатие сочетания **включает** интервал, 2-е — **выключает**. Секунды можно подать проводом от ноды «Число» |

Триггеры плагина **«Триггеры»** (15 нод, без входов — только выход; у «Изменения
файла/папки» ещё выход **path** — полный путь к файлу):
| Нода | Что делает |
|---|---|
| **Мышь в области** | курсор вошёл в прямоугольник X,Y,Ш,В |
| **Расписание** | время ЧЧ:ММ + дни (пн,вт…; пусто = все) или cron («*/30 * * * *») |
| **Запуск программы** | появился процесс (имя.exe, PID или кусок пути) |
| **Закрытие программы** | процесс завершился |
| **Смена активного окна** | окно с заголовком/классом стало активным (пусто = любая смена) |
| **Изменение файла/папки** | создан/изменён/удалён/переименован; тумблер «Фильтр по расширению» + поле «txt, png»; тумблер «Вложенные папки» |
| **Буфер обмена** | новый текст / файлы / изображение (или что угодно) |
| **Сеть** | интернет появился / пропал / открылся порт (host:порт, напр. `192.168.1.1:80`) |
| **USB устройства** | подключение/отключение: съёмный диск или USB-периферия (мышь, наушники, телефон…) |
| **Батарея** | питание подключили/отключили, заряд ниже порога (ноутбуки) |
| **Пиксель изменился** | цвет точки экрана X,Y изменился |
| **OCR нашёл текст** | текст появился в области экрана (встроенный Windows OCR, офлайн; ставятся пакеты `winrt-* pillow`; нужен русский языковой пакет Windows) |
| **Голосовая команда** | микрофон услышал фразу; офлайн-распознавание Vosk (пакеты `vosk pyaudio` ставятся сами, модель ~45 МБ один раз скачивается в `plugins/triggers/_model`) |
| **Громкость выше порога** | уровень микрофона превысил порог 0–1 (те же пакеты); микрофон держится открытым — реагирует сразу |
| **Элемент UI активен** | фокус UI Automation на элементе с именем (нужен `comtypes`) |

Если триггеру не хватает пакетов, в консоль печатается **готовая команда для
копирования** — вставьте её в cmd/PowerShell и нажмите Enter. Все пакеты
ставятся в папку самого плагина, ничего вручную ставить не нужно.

ПКМ на триггере → **«▶ Тест»** — вручную выстрелить для проверки.
В записи хоткея (кнопка ⏺ у параметра) просто **зажмите сочетание и отпустите**.
Запись идёт на сервере (глобальный слушатель), поэтому доступны даже системные
сочетания вроде **Alt+Tab**, которые браузер перехватывает. Esc — сброс.

### Условия и ветвления (плагин «Условия»)
У **каждой** ноды два выхода и переключатель **«Ждать»**:
- выход **true** — срабатывает при положительном результате проверки;
- выход **false** — при отрицательном;
- «Ждать»: **Нет** — одна проверка, событие сразу на true/false;
  **true** — нода крутит цикл (опрос каждые 0.25 с), **пока** условие не
  станет истинным, и только потом пускает цепочку дальше по ветви true;
  **false** — то же, но ждёт отрицательного результата.
  Прервать ожидание — кнопкой «Стоп».
  Выбрать оба значения одновременно нельзя — это один переключатель.

| Нода | Что проверяет |
|---|---|
| **Если** | безопасное выражение: `count > 3`, `name == "Аня" and x < 10`. Имена — переменные KeyFlow; арифметика, сравнения, `and/or/not/in`. Функции и импорты запрещены |
| **Switch / Case** | значение совпало с одним из вариантов (по строке или через запятую) |
| **Сравнить переменные** | `== != > < >= <=` (числа, если оба похожи на числа), `contains`, `starts`, `ends`, `regex`, `empty` |
| **Файл существует** | путь существует / это файл / это папка |
| **Процесс запущен** | по имени.exe, PID или куску пути |
| **Активное окно** | заголовок / класс / процесс-владелец: содержит, равно, regex |
| **Текст в окне / OCR** | «окно» — реальные тексты окна через WinAPI (заголовок, кнопки, подписи); «OCR» — область экрана (встроенный Windows OCR, офлайн) |
| **Буфер обмена** | текст буфера: содержит / равно / начинается / заканчивается / regex, тумблер «Без учёта регистра» |
| **Время / день недели** | сейчас внутри диапазона ЧЧ:ММ (можно через полночь) и день из «пн,вт,…» (пусто = все) |
| **Интернет доступен** | ping (ICMP, по умолчанию 1.1.1.1) / HTTP GET по URL / TCP host:порт |
| **Заряд батареи** | выше/ниже порога % (нет батареи — ветвь false) |
| **Переменная пустая** | пуста/не пуста (нет, None или одни пробелы); провод `value` сильнее имени переменной |

Провод, подключённый к входу с именем параметра (left, right, value, path,
name…), подменяет этот параметр — как у остальных нод KeyFlow.

### Действия
Мышь: клик ЛКМ/ПКМ/СКМ (одинарный, двойной, зажать, отпустить) в текущей
позиции / по координатам; двигать мышь (в X,Y) — **рывком** или **плавно**
(за N секунд, с мягким разгоном и торможением); позиция мыши.
Клавиатура: нажать клавиши (тап/зажать/отпустить — например «зажать shift»),
напечатать текст.
Система: подождать N сек, скриншот (по умолчанию папка `screenshots/`, вход
`path` — папка или `.../file.png`), запустить программу, буфер обмена, лог.
Переменные: **записать / прочитать** — единственный параметр «Название
переменной» (общие для всех цепочек workflow), на вход принимается любой тип,
на выходе — тот же тип, что сохранили.
**Константы**: **Число / int** (выход `int`) и **Текст / text** — значения
проводом: `Число → x/y скриншота или клика`, `Число → seconds` ожидания,
`Текст → message` лога, `Текст → text` печати. **Разбор позиции** раскладывает
позицию мыши на `x` и `y`. Провод подменяет параметр ноды.
Логика: условие с выходами true/false. **Превью** (в плагине ядра `core_nodes`):
показывает значения входов текстом прямо на ноде — числа, текст, bool, позиции (`x y`).
Первый вход **in** — белый (событийный, принимает только линии из выходов `out`).
Превью перерисовывается только когда пришёл сигнал в белый **in** — данные сами
по себе (константы на старте) рендер не будят. Каждая строка — «ИмяНоды:
значение» (имя ноды-источника сообщает движок); если пришло чистое событие без
данных — строка «Из: ИмяНоды». Точки входов окрашиваются по типу подключённого
провода (int — синий, string — жёлтый, событие — белый и т.д.), серые точки
данных нумеруются с **in1**.
Следующий вход добавляется сам, когда предыдущий занят, отключение входа
сдвигает остальные; между значениями — серая перегородка. Многострочное
значение (например, из ноды «Текст») показывается несколькими строками.
В поиске нод «Превью» стоит сразу после «Подождать». Поле «Текст» у ноды
**Текст (String)** растягивается: потяните за нижний край ноды (высота) или за
правый нижний угол (сразу высота и ширина) — курсор подскажет; клик по полю
открывает большое окно ввода.
Веб (плагин `web_tools`): **открыть сайт**, HTTP-запрос, извлечь текст по
регулярке.

### Пример из жизни
`Горячая клавиша (a+s+d)` → `Подождать 5 сек` → `Скриншот` →
→ ветвь 1: `Переменная: записать A ← Позиция мыши`, ветвь 2: `Запустить программу`
(обе ветви выстреливают вместе, но ноды исполняются по очереди).

## Stream Deck

В Stream Deck на кнопку поставьте действие **System: Hotkey** и укажите то же
сочетание, что в ноде «Горячая клавиша» (например `ctrl+alt+1`). Панель шлёт
хоткей глобально — KeyFlow его ловит и запускает цепочку. Так каждой кнопке
панели соответствует своя нода-триггер.

* Важно: сочетание должно быть «не занято» системой/браузером.
  Stream Deck может отправлять и **мультимедийные/редкие** клавиши (F13–F24) —
  их тоже можно ловить.

## Плагины

* Каждая нода принадлежит плагину (папка в `plugins/` с `plugin.json` +
  `plugin.py` с функцией `register(api)`).
* **Само ядро — тоже плагин** (`core_nodes`).
* Сломанный плагин не валит программу: он помечается ошибкой во вкладке
  **Настройки → Плагины** (там же включение/выключение и перезагрузка).
* **Импорт/экспорт**: во вкладке «Плагины» кнопка **⤒ Импорт (.zip)** —
  выбрать zip-архив плагина; кнопка **⤓** у каждого плагина — скачать его zip.
* В комплекте `broken_example` — намеренно сломанный плагин (выключен):
  включите его, чтобы увидеть изоляцию вживую.

## Python-окружение и пакеты

* Программа работает в **своём локальном окружении `.venv`** (создаётся
  автоматически при первом запуске `run.bat`) — основной Python системы
  не засоряется.
* Обязательные пакеты ядра (`pynput`, `mss`, `requests`) ставятся в `.venv`
  при каждом запуске (если уже стоят — мгновенно).
* **Необязательные пакеты плагинов ставятся сами** — и сразу **в папку
  плагина** (`plugins/<имя>/_packages`): если триггеру не хватило пакета
  (OCR, голос, watchdog…), движок при запуске воркфлоу ставит его туда фоном
  и **сам перезапускает ноду**. Папку плагина можно целиком копировать на
  другую машину — вместе с зависимостями.
  В консоль печатается прогресс и готовая команда для копирования на случай,
  если pip не справился. Ручная установка пакетов не нужна: всё нужное
  конкретному плагину всегда живёт в его собственной папке.
* OCR использует **встроенный Windows OCR** (Windows.Media.Ocr) — офлайн,
  без внешних программ. Единственное требование: в Windows установлен
  нужный языковой пакет (для русского — «Параметры → Время и язык →
  Язык и регион → русский», компонент «распознавание текста»).
* «Голосовая команда» распознаёт **локально** (Vosk, офлайн): после первой
  установки пакетов модель скачивается сама (~45 МБ, один раз) в
  `plugins/triggers/_model` — дальше интернет не нужен, реакция почти мгновенная.

Минимальный плагин:

```python
# plugins/my_plugin/plugin.py
def register(api):
    api.add_node({
        "id": "my/upper",                      # plugin/name
        "title": {"en": "Upper", "ru": "ВЕРХНИЙ РЕГИСТР"},
        "category": "system",
        "inputs": [("in", "event"), ("text", "string")],
        "outputs": [("out", "event"), ("text", "string")],
        "params": [{"name": "suffix", "type": "string", "default": "!",
                    "label": {"en": "Suffix", "ru": "Суффикс"}}],
        "exec": exec,
    })

def exec(api, params, inputs, emit):
    api.check_stop()                       # уважать кнопку «Стоп»
    text = inputs.get("text") or params["suffix"]
    emit("text", str(text).upper())        # значение на выход -> дальше по проводу
    emit("out", None)                      # «событие» продолжает цепочку
```

`api`: `check_stop()`, `log(msg)`, `get_var/set_var`, `get_var_any`,
`inject()` (контекст-менеджер — подавляет реакцию триггеров на собственные
нажатия; окно динамическое: молчим, пока нода внутри `with`, затем окно
тухнет за ≤0.5 с — раньше фиксированных секунд не было). Триггер-ноды вместо
`exec` объявляют `"trigger": True` и `"start": fn(handle, node)`;
выстрел — `handle.fire(value)`.

## Настройки

* **Язык**: RU / EN (применяется после перезагрузки страницы — автоматически).
* **Тема**: тёмная (по умолчанию) / светлая.
* **Стиль линий**: плата / кривые. **Сетка**: выравнивание нод.
* Хранятся в `settings.json`, workflows — в `workflows/*.json`
  (автосохранение + Ctrl+S), скриншоты — в `screenshots/`.

## Нюансы

* Глобальные хоткеи ловятся **везде**, включая браузер с открытым KeyFlow:
  не назначайте триггеры на обычные буквы без модификаторов, пока включен ▶.
* Сочетания из 3+ букв (`a+s+d`) срабатывают, когда все клавиши зажаты
  одновременно — «хордовые» аккорды как в играх.
* Если нода покраснела — наведите/откройте журнал: там причина. Соседние
  ветви при этом продолжают работать.
* Защита от зацикливания: цепочка длиннее 500 переходов обрывается.
